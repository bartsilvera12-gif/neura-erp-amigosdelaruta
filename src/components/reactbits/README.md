# React Bits

Componentes traídos de [React Bits](https://reactbits.dev) vía su registry
(`https://reactbits.dev/r/<Nombre>-TS-TW.json`).

Se guardan acá tal cual vienen, con un único cambio: el import de `motion/react`
se reemplaza por `framer-motion`, que es el paquete que ya usa el proyecto
(mismo código, sólo cambia el nombre del paquete). No agregar dependencias
nuevas para estos componentes.
